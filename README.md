# EcoWise – Environmental Quiz
## Project Overview
EcoQuiz is an interactive educational quiz developed as part of the EcoWise group project for the Web Design and Development module at the National College of Ireland (NCI). This project focuses on **Sustainable Development Goal 12: Responsible Consumption and Production**, aiming to educate users about recycling, waste reduction, material reuse, and the principles of sustainability.
## Features
- **10 Questions:** The quiz includes 10 questions centered on sustainability and environmental awareness.
- **Randomized Questions:** Each game session features 5 questions randomly selected from the pool of 10.
- **No Repetition:** The same question will not appear more than once in a single game session.
- **Multiple Choice:** Each question offers four possible answers.
- **Instant Feedback:** Users receive immediate feedback after selecting an answer.
- **Scoring System:** Each correct answer earns 1 point, with a maximum possible score of 5/5.
- **Progress Indicator:** Tracks your progress through the five questions.
- **Results Screen:** Displays your final score along with a message based on your performance.
- **Retry Option:** Allows you to restart the quiz with a new, randomly selected set of questions.
- **Responsive Design:** The layout automatically adapts to fit both desktop and mobile screens.
## Technologies Used
- **HTML5** — Site structure and content.
- **CSS3** — Custom, eco-themed design consistent with the EcoWise brand.
- **Bootstrap 5.3.8** — Responsive layout, navigation, buttons, and UI elements.
- **JavaScript** — Random selection of questions, answer validation, score calculation, and quiz functionality.
## How to take the quiz
1. Download the `ecoquiz.html` and `quiz.css` files.
2. Save both files in the same folder.
3. Open `ecoquiz.html` in a web browser.
4. Select your answer, check it, and complete the quiz.
An internet connection is required to load Bootstrap from a CDN.
